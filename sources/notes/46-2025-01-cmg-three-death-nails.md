# 46. CMG On My Radar — The Three Death Nails (2025-01-24, 2025-02 목록)
출처: https://www.cmgwealth.com/ri/on-my-radar-stanley-druckenmiller-the-three-death-nails · #41 NBIM(2024-11) 인터뷰를 정리한 2차 자료

- **'세 개의 관 못(three death nails)'**: 금리·달러·유가가 **동시에** 오르면 시장에 불이 켜진다 → 기존 `profit_headwind`(이익 역풍) 툴과 정확히 같은 규칙. 2024년 11월에도 같은 말을 반복 = 그가 계속 쓰는 핵심 규칙
- 2024년 11월 당시: 기업 이야기를 들어보면 주택 외엔 뚜렷한 약세 없음 / 금융여건 여전히 느슨 / 1970년대식 인플레 재반등 걱정 / 연준이 너무 일찍 승리 선언(스프레드 타이트·시장 강한데 인하) / 연준이 마음을 못 바꾼다(포워드 가이던스)
- 포지션: **10년물 국채 숏(NAV의 25% 상당)** — "연준이 인하한 바로 그날 연준을 숏했다" / 좁은 시장 주도(소수 종목)는 '노란불'
- 원칙: 18~24개월 앞을 본다 / 먼저 사고 나중에 분석 / 손실에 감정 없음, 매입가는 무관 / 4개 자산군 롱·숏 / "연준의 첫 임무는 큰 실수(70년대, 금융위기, 최근 인플레)를 피하는 것 — 미세조정·연착륙 걱정이 아니다"
- 방향표 근거: 느슨한 여건 속 인하 → 채권 −(국채 숏). 시장 폭 협소 → 주식 경계(노란불)
