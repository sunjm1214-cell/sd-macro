# 32. NBIM 연례 투자 컨퍼런스 2023 (2023-04-27, 오슬로, 니콜라이 탕엔)
출처: https://www.youtube.com/watch?v=dXxWajc-tgI · 18분

- 11년 공짜 돈 + 넓은 자산 버블 + 12개월 500bp — 역사에서 시나리오를 찾는 사람에게 특히 어려운 시기. 2년 전(2년물 0.15%, 통화 +30%)은 쉬웠다
- **5~6개 자산군 → 볼이 안 보일 때 안 친다**. 경착륙 진영(올해 후반)이지만 큰 베팅 안 함: 2년물 4% 미만·기준금리 5.25%면 채권을 사려면 경착륙이 확실해야, 10년물 3.5%는 헐값 아님 + 파월이 경착륙에 공격적으로 완화하면 인플레가 다시 → 채권 비매력
- SVB 대응: 4일 만에 5~6개월치 QT를 되돌릴 만큼 찍어냄 → 경착륙 시 연준이 버티리라 믿기 어렵다(아서 번스보다 나쁠 수도)
- 주식: 억지로 하나 고르면 러셀2000 같은 구경제·경기민감 숏. 그러나 엔비디아처럼 침체 속에서도 군비경쟁으로 급성장하면 안 빠질 수 있다 → 주식 복잡
- **달러 숏 = 유일하게 위험을 건 곳** — 통화 추세는 최소 2~3년, 지난 10년 13조 달러 유입. 지난 9개월 달러 랠리를 놓친 건 경력 최대의 실수(바이든·파월을 믿지 못해서). 앞으로 미국의 긴축은 외국보다 덜할 것 + 달러 무기화로 탈달러 논의. 금도 같은 이유로 롱
- 주식 순숏 3%(사실상 0), 채권은 JGB 숏(위험보상 터무니없음 — 2년 전 미 2년물을 조금 닮음, 단 정부 행동에 좌우), **P&L 하루 변동 30~40bp 수준으로 단추를 채움**
- 손실 회피의 수학: −50%면 +100% 필요 → 나쁜 해는 0~5%, 공이 보일 때 50~60% (99%가 '전부 20~30%'가 아님, 5·7% 해가 많았다)
- 차트는 ① 남들이 안 보는 걸 찾는 도구(변화율 지표가 선행) ② 아이디어에 빠지지 않게 하는 규율 — 펀더멘털과 차트가 서로를 규율
- 반대 의견을 말하는 젊은 직원을 둔다 — 늘 동의만 하면 오래 못 있음
- 가격 vs 뉴스는 20~30년 전만 못하다(헤지펀드·팩터·퀀트가 같은 걸 배움). 그래도 강세 논리가 맞는데 주가가 안 가면 논리를 다시 확인
- 향후: 10년 뒤 주가가 더 높지 않아도 놀랍지 않다(1968~82), 큰 스윙은 있다(70~72, 76~78) → 인내. 통화시장 매우 흥미
