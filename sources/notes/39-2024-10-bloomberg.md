# 39. Bloomberg Markets 특별편 (2024-10-16) — 연준·대선·채권·엔비디아
출처: https://www.youtube.com/watch?v=-4NuOAfZjHo · 21분 · 기존 RULES 'Bloomberg 2024'(채권 황금률·금융여건)의 원 영상

- [1-유동성·연준] 2021과의 비교: 2021엔 확신(통화량 +40%, 호황) — 인플레가 2%를 넘고 **13개월 뒤에야 인상**, 그 사이 2조 채권 매입 = 포워드 가이던스의 덫. 지금은 더 미묘하지만 **비대칭**: 그땐 인플레 8.5%까지 기다려 놓고 이제 목표(2.5~3.25%) 위인데 50bp 인하
- "실질금리 기준으로 긴축적"이라는 이론 대신 **시장을 본다(시장이 교수보다 예측을 잘한다)**: 주식 사상 최고, 금 사상 최고, GDP 추세 이상, 신용 타이트, 은행 실적 양호, 크립토 광풍 → 제약의 흔적 없음
- 70년대: 인플레 8→3% 내려온 뒤 75년 침체로 완화 → 12%로 재상승. "금융시장 멜트업 속에 완화 + 재정 확장"은 위험. 다시 긴축해야 하면 시장과 연준 독립성에 악몽 — 연준의 진짜 위협은 정치보다 연준 자신의 큰 실수
- **선거도 시장 내부로 읽는다**(1980 레이건 때처럼): 최근 12일 은행주·크립토·DJT·규제완화 수혜 업종이 앞섬 → 트럼프 우세
- 시나리오: 블루 스윕(가능성 매우 낮음) → 세금·기업심리 악화로 주식 3~6개월 고전(가계 금융자산 중 주식 25%, 사상 최고라 경제로 전이) / **레드 스윕** → 야성적 충동·규제완화로 3~6개월 경기 강세, 그러나 채권이 이미 경제를 반영 못해 **채권이 나쁘게 반응 → 주식 랠리를 꺼버릴 수 있음**, 연준도 더 매파 → **"원인(채권)을 치지 증상(주식)을 치지 않는다"** — 채권으로 플레이
- 산업정책(양당 모두)·관세 반대, 감세 > 지출(자본 축적 vs 정부가 대체), 엔타이틀먼트를 뺀 트럼프에게 재정 F
- 엔비디아: 800~950에 매도 → 1,300 — 큰 실수. 1년에 3배 → 밸류 부담. AI는 장기 신봉, **전력 인프라**로 플레이 중. 가격이 내려오면 재진입
- **채권 숏 논리 (황금률)**: 50bp 인하한 날 숏. 단기 방향 의견은 없음 — 파월이 틀려 인플레가 가속하면 수백 bp, 맞으면 25~30bp 손실 → 비대칭. **10년물은 명목GDP(5.5%) 근처에서 거래돼야** → 위험보상상 숏

방향표 근거: 인하 + 시장이 말하는 느슨한 여건 → 채권 −. 레드 스윕(성장 + 재정) → 채권 − → 주식 랠리 제약. 시장 폭/업종 상대강도로 정치 결과까지 읽는다
