# 48. Lost Tree Club 강연 + Q&A (2015-01-18; Daniel Scrivner 2025-07 재게재)
출처: https://www.danielscrivner.com/stanley-druckenmiller-rare-lost-tree-club-lecture (읽은 사본: aryadeniz.substack.com 전문 녹취) · 기존 RULES의 'Lost Tree 2015'와 같은 강연, 이번엔 전문으로 세부 확인

## 원칙의 원전 (그의 첫 멘토 스페로스 드렐스에게서)
- 교훈 1: 현재로 투자하지 마라 — **약 18개월 뒤** 모습을 그려라, 가격은 그 미래로 움직인다
- 교훈 2: **이익이 시장 전체를 움직이지 않는다 — 중앙은행과 유동성이 움직인다**
- 분산은 경영대학원의 가장 잘못된 개념 → 진짜 기회는 1년에 1~2번, 보이면 크게 걸고 바구니를 지켜본다
- 소로스에게서 배운 것: 확신이 크면 크게(타율은 내가 높았지만 장타율은 소로스) — 1992 파운드: 70억 펀드 중 15억 → 분데스방크 발언 보고 100% → 소로스 "200%로" → 총 150억 노출
- 젊은 경험 부족이 강세장에서 과감함으로 작동(26세 CIO)

## [1-유동성·연준] 증거와 사례
- **큰 수익의 약 80%는 중앙은행 실수가 만든 주식 약세장에서**
- 1979 이란 혁명 후: 석유 70%·방산 30%·채권 0 → +100% (S&P 보합)
- 볼커가 단기금리 18% 유지할 때 자본 절반을 14% 30년물 국채에 → 주식 약세장 속 채권 랠리, +40%
- 2003~04: 기준금리 1% vs 명목성장 ~9% → 직원들 '적정 금리' 3~6% → 과잉 완화 결론 → 2005 중반 서브프라임 보임 → 2006엔 이름, 2007~08 수익
- 2015 진단: 가계 순자산 2007 고점 돌파, 실업 5.6%, 산업생산·소매 상승 추세, 근원 CPI 디플레 없음 → **제로금리·QE 5~6년은 연준 102년 역사상 전례 없음** → 위험 곡선 밖으로 밀어냄(의도치 않은 결과), 소비 효과는 줄고 부작용 비용은 안 줄어든다
- 경고 신호: 신규 IPO 80% 적자(1999 이후 처음), 시총/GDP 100년 최고(1999~2000 9개월 제외)

## [1-이익·신용] 신용 과잉 체크리스트 (Q&A)
- 회사채 발행 1.1조(2013~14) vs 7천억(2006~07) / B등급 비중 28%→71% / 커버넌트 라이트 <20%→>60% / 자사주 매입용 차입 5,670억 / 장부가치 정체 속 부채만 증가 / 하이일드 발행 18%가 에너지
- 단 "당장 붕괴 예측 아님" — 2004에도 같은 걱정, 문제는 2년 뒤에 옴 → **신용 과잉은 '얼마나(크기)'이지 '언제'가 아님**

## [1-통화]
- 미국이 세계의 중앙은행. 일본이 안 찍자 엔 강세 → 경기 타격 → 결국 찍음
- 유로 약세 지속 전망(독일과의 비용 격차, 디플레, 주변국 경직) — "이 정도 길이의 통화 추세는 빨리 안 뒤집힌다"

## [3-표현] 
- 순숏 아님. 연착륙도 가능, 다만 이런 정책이면 나쁜 결말을 경계해야 한다
- 인플레/디플레 모두 불확실: 자산 버블 붕괴·은행 수익률곡선 역전·유가 붕괴가 디플레 경로

## [4-자기점검] 최대 실수
- 1999 초 인터넷주 2억 숏 → 3월까지 6억 손실 → 공격적 기술주 매니저 고용해 +35%로 마감 → 2000년 1월 나오고 싶었지만 3월에 60억 기술주 매수(고점) → 6주에 30억 손실. "이미 알던 걸 감정 때문에 어겼다"
- 좋은 매니저 기준: 열정, 약세장 성과, 열린 마음·겸손(실수를 말한다), 정직

## [배경] 재정·세대
- 노인 빈곤 30%→9%, 아동 빈곤 21%→25%; 엔타이틀먼트가 연방지출의 28%(1970)→72%; GAAP 기준 부채 205조; 하루 1.1만 명이 65세 → 2024~25년부터 재정 압박 (기후변화처럼 멀어 보이지만 기다리면 못 고침)
